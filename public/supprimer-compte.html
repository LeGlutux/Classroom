Supprimer le compte

Pour effacer ton compte Thòt Note et les données de classe (élèves, croix, listes, plan) :

  1. Ouvre Thòt Note (site ou application).
  2. Va dans Paramètres.
  3. Choisis Supprimer le compte.
  4. Entre ton mot de passe pour confirmer.

Le login et les données sont alors supprimés. Tu peux aussi écrire à lp.bendeks@gmail.com depuis l’adresse du compte.
